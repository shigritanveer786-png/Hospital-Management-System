# Hospital Management System (C++)

A beginner-friendly console-based Hospital Management System made for Dev-C++ 5.11.

## Features
1. Add and view patients
2. Search a patient by ID
3. Add and view doctors
4. Book and view appointments
5. Create and view patient bills (PKR)

## Requirements
- Dev-C++ 5.11
- Windows PC

## How to open and run in Dev-C++ 5.11
1. Extract this ZIP file to a folder.
2. Open Dev-C++.
3. Select File > Open.
4. Open `Hospital_Management_System.cpp`.
5. Select Execute > Compile & Run (or press F11).
6. The program will open in a console window.

## Data storage
When you add records, the program creates these text files in its current working folder:
- patients.txt
- doctors.txt
- appointments.txt
- bills.txt

Keep these files with your program if you want to retain your sample records. Make a backup before deleting or moving them.

## Notes
- This is an educational demonstration project, not a production hospital system.
- It does not provide secure accounts, encryption, backups, or privacy controls.
- Use fictional sample data only. Do not enter real patient medical or personal information.
- IDs should be unique. The program stores entries as simple text records.
